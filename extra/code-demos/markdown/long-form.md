# Release notes draft

Nushu is a warm, low-contrast theme. This file is prose-heavy, for judging
how the theme reads over a long stretch of text rather than a feature list.

## Why low contrast

Pure black on pure white can be tiring over a long session, especially for
people with **astigmatism**. Nushu softens both ends: backgrounds lean toward
paper, and text leans toward ink. Accents borrow from GitHub's *Primer*
palette, so links, strings, and keywords still feel familiar.

## What changed

1. Variables now use warm grays that match the background.
2. Constant symbol icons render correctly in **Nushu Dark**.
3. The README has a new animated header.

> Good defaults are invisible. You notice them only when they're missing.

### Upgrading

Install from the Marketplace, then run `Preferences: Color Theme` and pick
**Nushu Light** or **Nushu Dark**. See the [README](../../../README.md) for
screenshots, and the [changelog](../../../CHANGELOG.md) for history.
