# Code demos

Sample files for checking Nushu's syntax highlighting. Open this folder in an
Extension Development Host (F5) and flip between Nushu Light and Nushu Dark.

Each file tries to cover the common token types for its language: comments,
keywords, strings with interpolation, numbers, types, functions, decorators,
and punctuation. `markdown/` has several files covering CommonMark, GitHub
extensions (tables, task lists, alerts, footnotes), and fenced code blocks
in other languages. `markedit-markdown.md` and `markedit-code-blocks.md` are copies
of the demos in [markedit-theme-nushu](https://github.com/wheredoesyourmindgo/markedit-theme-nushu)
(`demo/markdown.md` and `demo/code.md`), so both themes can be compared on the same files.

This folder is excluded from the published extension (see `.vscodeignore`).
